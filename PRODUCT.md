# Product Requirements Document (PRODUCT.md)

## Product Name
ButuanEV Battery Rental System

## Tagline / One‑Liner
A full‑stack rental platform for ButuanEV electric‑vehicle battery swapping and monitoring.

## 1‑Sentence Pitch
Empowers EV fleets and individual riders in Butuan to swap depleted batteries for charged ones instantly, while giving fleet operators real‑time visibility and analytics.

## 2. Problem Statement
- EV owners/drivers experience range anxiety and long downtime when batteries run out.
- Fleet operators lack a centralized, real‑time system to track battery status, rental transactions, and maintenance needs.
- Existing manual processes are slow, error‑prone, and offer no visibility into SOC (State of Charge) or unit health.

## 3. Target Audience
| Segment | Persona | Key Needs |
|---|---|---|
| **EV Rider / Driver** | Daily commuter or fleet driver in Butuan | Quick battery swap, transparent pricing, easy booking via mobile/desktop |
| **Fleet Operator** | Small‑to‑medium business managing multiple EVs | Real‑time SOC monitoring, transaction history, maintenance alerts, revenue reports |
| **System Admin** | IT/operations person | User management, settings, integration with backend services |

## 4. Core Features (MVP)
1. **Authentication & Onboarding** – Secure sign‑up/login, role selection (rider vs operator).
2. **Battery Inventory View** – List all batteries with SOC, location, and health status.
3. **Rental Workflow** – New rental request, battery release, battery return, and status updates.
4. **Dashboard** – Tabbed view switching between dashboard, activities, rentals, inventory, drivers, payments, reports, and settings.
5. **Modals** – Voucher, receipt, rental detail, and driver profile modals for ancillary actions.
6. **Payments & Reports** – Generate revenue reports, filter by date, view payment summaries.
7. **Settings** – User preferences, system configuration.

## 5. User Flows
- **Rider onboarding** → Select role → Browse available batteries → Initiate rental → Swap battery → Return battery → Receive receipt.
- **Operator dashboard** → View overview → Filter batteries → Manage rentals → Generate reports → Adjust settings.

## 6. Technical Constraints & Assumptions
- **Frontend framework**: React (v19) with Vite, TypeScript, Tailwind CSS.
- **State management**: Custom `RentalContext` (provider pattern).
- **Styling**: Tailwind utility‑first, using ButuanEV navy (`#002353`), cyan (`#06BAD1`), and green (`#248D1F`) with cool slate neutrals; red and amber remain operational warning colors.
- **Backend**: Express API (defined elsewhere) with JWT auth, Gemini AI integration (`@google/genai`).
- **Data mocking**: `src/data/mockData.ts` provides sample data for now.
- **Responsive**: Mobile‑first; sidebar collapses on small screens.
- **No SSR** for now; client‑side routing via React Router‑like tab switching.

## 7. Out‑of‑Scope (for MVP)
- Native mobile app (web‑only).
- Hardware‑level battery communication (SOC reported by backend).
- Multi‑currency or complex pricing rules.
- Integration with external mapping or GPS.

## 8. Success Metrics (post‑launch)
- **Swap throughput**: average time from rental request to battery swap (target < 3 min).
- **User adoption**: % of registered riders who complete a first swap within 7 days.
- **Operator satisfaction**: Net‑Promoter Score (NPS) > 30 after first month.
- **System uptime**: > 99.5 % during peak hours (18:00‑22:00 local time).
